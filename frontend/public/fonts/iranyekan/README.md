# IRANYekanX font files

This directory intentionally contains no font binaries.

Copy your **licensed** WOFF2 files here using these exact names:

- `IRANYekanX-Regular.woff2`
- `IRANYekanX-Medium.woff2`
- `IRANYekanX-Bold.woff2`

The application references them from `/fonts/iranyekan/...`.

If your licensed package uses different filenames, either rename your local copies to the names above or update `frontend/src/app/fonts.css`.
