درس ۱۵ • Lesson 15

Les indéfinis — کلمات نامعین

آموزش کامل تعیین‌کننده‌ها و ضمیرهای نامعین در زبان فرانسه، همراه با تفاوت‌های ظریف، استثناها، اشتباهات رایج و تمرین‌های درس.

1 مفهوم کلی کلمات نامعین

کلمات نامعین به شخص، شیء، تعداد یا مجموعه‌ای اشاره می‌کنند که دقیقاً مشخص نشده است.

تعیین‌کننده / صفت نامعین

قبل از اسم قرار می‌گیرد و اسم همچنان در جمله حضور دارد.

quelques étudiants
چند دانشجو
chaque étudiant
هر دانشجو
aucun étudiant
هیچ دانشجویی

ضمیر نامعین

جای اسم را می‌گیرد؛ بنابراین اسم دیگر تکرار نمی‌شود.

Quelques-uns sont absents.
چند نفر غایب‌اند.
Chacun a un livre.
هرکدام یک کتاب دارند.
Aucun n’est absent.
هیچ‌کدام غایب نیستند.
نکتهٔ اصطلاح‌شناسی کتاب از اصطلاح adjectif indéfini استفاده می‌کند. در بسیاری از دستورهای جدیدتر، برای مواردی که پیش از اسم می‌آیند اصطلاح déterminant indéfini نیز به‌کار می‌رود.

2 quelques — چند، تعدادی

quelques + nom pluriel

برای تعداد کم و نامشخصی از افراد یا اشیا استفاده می‌شود.

J’ai quelques amis à Montréal.
چند دوست در مونترال دارم.
Nous avons quelques questions.
چند سؤال داریم.
نکتهٔ مهم quelques در معنای «چند تا» همیشه با اسم جمع می‌آید.
اشتباه رایج quelques livres ✓    quelque livres ✗

اما شکل مفرد quelque نیز وجود دارد

quelque temps quelque difficulté quelque chose quelqu’un
تلفظ و liaison پیش از اسم آغازشده با مصوت، معمولاً اتصال صوتی شنیده می‌شود:
quelques amis → /kɛlk.z‿ami/

3 plusieurs — چندین

plusieurs + nom pluriel
Plusieurs étudiants ont posé la même question.
چندین دانشجو همان سؤال را پرسیدند.
کلمه برداشت معمول مثال
quelques چند تا، تعداد نسبتاً کم quelques pages
plusieurs چندین، بیش از یکی و معمولاً تعداد بیشتر plusieurs chapitres
بین quelques و plusieurs مرز عددی ثابت و ریاضی وجود ندارد؛ انتخاب آن به برداشت گوینده و موقعیت بستگی دارد.
شکل مؤنث جدا ندارد plusieurs femmes ✓    plusieures femmes ✗

4 chaque — هر، تک‌تک

chaque + nom singulier + verbe singulier
Chaque étudiant a un livre.
هر دانشجو یک کتاب دارد.

با وجود اینکه از نظر معنا چند نفر در نظر گرفته شده‌اند، chaque هر عضو را جداگانه در نظر می‌گیرد؛ بنابراین اسم مفرد است.

chaque étudiant ✓
chaque étudiants ✗

تفاوت chaque و tous les

Chaque étudiant a un dossier.
هر دانشجو، به‌صورت جداگانه، پرونده‌ای دارد.
Tous les étudiants ont un dossier.
تمام دانشجویان پرونده دارند.
زاویهٔ دید chaque نگاه فردبه‌فرد و توزیعی دارد؛ tous les کل گروه را در نظر می‌گیرد.

استفاده با زمان

chaque jour chaque semaine chaque mois chaque année
برای فاصلهٔ عددی، از chaque استفاده نمی‌کنیم
chaque deux jours ✗
tous les deux jours ✓
toutes les trois semaines ✓
برای «یک روز در میان» ساخت دقیق‌تر:
un jour sur deux

وقتی اسم حذف می‌شود

Chacun a un livre.
هرکدام یک کتاب دارند.
Chaque a un livre. ✗
Chacun a un livre. ✓

6 certains / certaines — بعضی

Certains étudiants travaillent.
بعضی دانشجویان کار می‌کنند.
Certaines personnes préfèrent rester seules.
بعضی افراد ترجیح می‌دهند تنها بمانند.
certains + nom masculin pluriel
certaines + nom féminin pluriel
معنای certain به جایگاه آن بستگی دارد
Certains étudiants sont absents.
بعضی دانشجویان غایب‌اند.
un résultat certain
یک نتیجهٔ قطعی
un certain monsieur
آقایی خاص / فردی مشخص ولی نام‌برده‌نشده

7 d’autres — افراد یا چیزهای دیگر

Certains étudiants habitent seuls, d’autres vivent en couple.
بعضی دانشجویان تنها زندگی می‌کنند و بعضی دیگر با شریک زندگی می‌کنند.
J’attends d’autres étudiants.
منتظر دانشجویان دیگری هستم.
ساخت معنا / کاربرد
d’autres étudiants دانشجویان دیگری؛ گروهی نامشخص
les autres étudiants بقیهٔ دانشجویان؛ گروه مشخص باقی‌مانده
des autres étudiants معمولاً حاصل de + les است
Je parle des autres étudiants.
دربارهٔ بقیهٔ دانشجویان صحبت می‌کنم.
برای «دانشجویان دیگری»:
d’autres étudiants ✓
des autres étudiants ✗

8 aucun / aucune — هیچ

ne + verbe + aucun / aucune + nom
Je ne connais aucun étudiant.
هیچ دانشجویی را نمی‌شناسم.
Je n’ai aucune question.
هیچ سؤالی ندارم.
با aucun معمولاً pas نمی‌آید
Je ne connais aucun étudiant. ✓
Je ne connais pas aucun étudiant. ✗

وقتی فاعل جمله باشد

Aucun étudiant n’est venu.
هیچ دانشجویی نیامد.
Aucune étudiante n’est absente.
هیچ دانشجوی زنی غایب نیست.

هماهنگی جنسیتی

aucun problème aucun livre aucune question aucune personne
چرا معمولاً مفرد است؟ چون معنای اصلی آن «حتی یک مورد هم وجود ندارد» است.

استثنای جمع

در مقابل برخی اسم‌هایی که ذاتاً یا معمولاً به شکل جمع استفاده می‌شوند، شکل جمع نیز ممکن است دیده شود:

aucuns frais aucunes funérailles
این کاربرد نسبتاً رسمی و کم‌بسامد است.

موقعیت‌هایی که ne دیده نمی‌شود

— Vous avez des questions ?
— Aucune.
Aucun problème !
مشکلی نیست!
sans aucun doute
بدون هیچ شکی
در گفتار روزمره ممکن است ne حذف شود:
J’ai aucun problème.
اما در نوشتار رسمی و آزمون بهتر است:
Je n’ai aucun problème.

16 تمرین‌های درس و پاسخ تشریحی

تمرین ۱ — چند، چندین، همه، هیچ

بر اساس اطلاعات یک گروه ۳۰ نفره، از quelques, plusieurs, tous, aucun استفاده کنید.

پاسخ
Plusieurs étudiants habitent chez leurs parents.
Quelques étudiants habitent à la cité universitaire.
Plusieurs étudiants cohabitent avec des amis.
Tous les étudiants habitent dans le centre.
Aucun étudiant n’habite à l’hôtel.
اگر تعداد بسیار کم باشد quelques، اگر چندین مورد باشد plusieurs، برای ۱۰۰٪ اعضا tous و برای صفر aucun مناسب است.

ساخت certains…, d’autres…

Certains étudiants habitent dans un studio, d’autres habitent dans un deux-pièces.
Certains vivent seuls, d’autres vivent en couple.
Certains sont propriétaires, d’autres sont locataires.

تمرین ۲ — خانوادهٔ tout

جمله را مانند الگوی زیر کامل کنید:

J’aime toutes les couleurs, mais surtout le bleu.
نمونه پاسخ
J’aime tous les fruits, mais surtout les pêches.
J’aime tous les légumes, mais surtout les asperges.
J’aime toutes les saisons, mais surtout l’automne.
J’aime toutes les fleurs, mais surtout les tulipes.
J’aime tous les animaux, mais surtout les chiens.
J’aime tous les sports, mais surtout le football.
J’aime tous les genres de musique, mais surtout le jazz.
شکل tout با اسم دسته هماهنگ می‌شود: fruits, saisons, fleurs, sports...

تمرین ۳ — chaque / tous / toutes

پاسخ
— Vous vous lavez les cheveux chaque jour ?
— Non, tous les deux jours.
— Vous changez de voiture chaque année ?
— Non, tous les trois ans environ.
— Vous allez chez le coiffeur chaque mois ?
— Non, toutes les deux semaines.

تمرین ۵ — انتخاب کلمه بر اساس تعداد
